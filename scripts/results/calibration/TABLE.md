`eval_noise_bits` is the worst value over the input patterns measured for
that cell. A cell qualifies only when every pattern decrypted, none
saturated the measurement, and the realised ring dimension did not exceed
`ring_dim_natural` -- the dimension the circuit already needs untouched.

The key is (circuit, ring_dim_requested, natural_mult_depth): all three are
known before a crypto context exists, which is what the parameter selection
in `src/util/params.cpp` looks up. For the threshold variant
`ring_dim_natural` exceeds `ring_dim_requested` on its own -- a degree-k
polynomial needs a long modulus chain, with or without flooding -- so growth
must be judged against it, not against the request.
